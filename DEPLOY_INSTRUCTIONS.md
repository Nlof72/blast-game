# Инструкция по деплою на GitHub Pages

## Шаг 1: Сборка проекта

1. Откройте проект в **Cocos Creator 2.4.x**
2. Перейдите: **Проект** → **Сборка**
3. Выберите платформу: **Web Mobile**
4. Убедитесь, что путь сборки: `build/web-mobile`
5. Нажмите **Сборка** и дождитесь завершения

## Шаг 2: Деплой

После успешной сборки выполните в терминале:

```bash
./deploy.sh
```

Скрипт автоматически:
- Создаст/обновит ветку `gh-pages`
- Скопирует файлы билда
- Запушет изменения на GitHub

## Шаг 3: Настройка GitHub Pages

1. Откройте репозиторий: https://github.com/Nlof72/blast-game
2. Перейдите: **Settings** → **Pages**
3. В разделе **Source**:
   - **Branch**: выберите `gh-pages`
   - **Folder**: выберите `/ (root)`
4. Нажмите **Save**

## Шаг 4: Проверка

Через 1-2 минуты игра будет доступна по адресу:
**https://Nlof72.github.io/blast-game/**

## Обновление деплоя

После любых изменений в проекте:
1. Соберите проект заново в Cocos Creator
2. Запустите `./deploy.sh`
3. Изменения появятся на сайте через 1-2 минуты

## Устранение проблем

### Ошибка "build/web-mobile not found"
- Убедитесь, что проект собран в Cocos Creator
- Проверьте путь сборки в настройках

### Ошибка при push
- Проверьте подключение к интернету
- Убедитесь, что у вас есть права на запись в репозиторий

### Страница не обновляется
- Подождите 2-3 минуты (GitHub Pages обновляется не мгновенно)
- Очистите кеш браузера (Ctrl+F5 или Cmd+Shift+R)
