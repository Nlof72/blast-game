# Tile Blast Game

Казуальная игра типа "blast" на Cocos Creator 2.4.x

## Описание

Игра-головоломка, где нужно уничтожать группы тайлов одного цвета, набирать очки и проходить уровни.

## Особенности

- Система уровней с увеличивающейся сложностью
- Специальные тайлы с различными эффектами
- Бустеры (бомба, перемешивание)
- Главное меню и система прогресса

## Технологии

- Cocos Creator 2.4.15
- TypeScript
- Архитектура: ООП/SOLID

## Установка и запуск

1. Установите Cocos Creator 2.4.x
2. Откройте проект в Cocos Creator
3. Нажмите "Проект" -> "Сборка" для сборки проекта
4. Для веб-версии выберите платформу "Web Mobile" или "Web Desktop"

## Сборка для GitHub Pages

1. В Cocos Creator: Проект -> Сборка
2. Выберите платформу: Web Mobile
3. Укажите путь сборки: `build/web-mobile`
4. После сборки содержимое папки `build/web-mobile` можно загрузить на GitHub Pages

## Структура проекта

```
assets/
  Script/
    core/        # Чистая логика игры (без зависимостей от Cocos)
    game/        # Правила игры и контроллер
    view/        # Компоненты отображения (Cocos)
    utils/       # Утилиты
  Scene/         # Сцены игры
  Prefab/        # Префабы
  Texture/       # Текстуры и спрайты
```
