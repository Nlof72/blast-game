# План тестов (механики)

Цель: покрыть ключевые механики игры после рефакторинга и обеспечить безопасное добавление новых фич.

## 1) Поиск групп (GroupFinder)
**Что проверяем:**
- корректный подсчет группы по цвету (4‑соседство);
- отсутствие диагонального соединения;
- корректное поведение на границах.

**Тест‑кейсы:**
- Группа 1: одиночный тайл → размер 1.
- Группа 2: L‑образная группа одного цвета → размер 3.
- Группа 3: диагональные тайлы одного цвета → размер 1 (не соединяются).
- Группа 4: смешанные цвета → группа считается только по стартовому цвету.

**Ожидаемое:** возвращаемая группа по координатам совпадает с вручную рассчитанной.

---

## 2) Наличие ходов (MoveAvailability)
**Что проверяем:**
- наличие хотя бы одной группы >= minGroupSize;
- наличие спец‑тайлов дает true независимо от групп.

**Тест‑кейсы:**
- Поле без групп размера >= minGroupSize → false.
- Поле с одной группой размера >= minGroupSize → true.
- Поле без групп, но есть спец‑тайл → true.

---

## 3) Эффекты (EffectHandlers)
**Что проверяем:**
- область удаления для каждого эффекта:
  - ClearRow
  - ClearColumn
  - BombRadius (с радиусом и default)
  - ClearBoard

**Тест‑кейсы:**
- ClearRow в середине → удаляет все непустые клетки в строке.
- ClearColumn на краю → удаляет все непустые клетки в колонке.
- BombRadius с radius=1 → квадрат 3x3 внутри границ.
- BombRadius у края → не выходит за границы.
- ClearBoard → все непустые клетки.

---

## 4) Создание спец‑тайла (SpecialSpawnPolicy)
**Что проверяем:**
- корректный выбор эффекта/радиуса по правилам.

**Тест‑кейсы:**
- tier [5..6] → эффект из списка ClearRow/ClearColumn.
- tier [7..8] → BombRadius с radius=1.
- tier [9..] → ClearBoard.
- groupSize меньше min tier → null.

---

## 5) Гравитация и спавн (GravitySystem)
**Что проверяем:**
- корректный сдвиг вниз;
- корректное создание новых тайлов;
- корректное создание спец‑тайла в колонке с кликом.

**Тест‑кейсы:**
- Удаление нескольких тайлов в колонке → оставшиеся сдвигаются вниз.
- Спавн новых тайлов заполняет верх.
- Спец‑тайл появляется в колонке клика (спавн или апдейт).

---

## 6) Ходы (MoveResolver)
**Что проверяем:**
- normal‑клик удаляет группу и вызывает гравитацию;
- special‑клик удаляет область эффекта;
- возвращает корректные moves/spawns/tileUpdates.

**Тест‑кейсы:**
- normal‑клик на группе < minGroupSize → null.
- normal‑клик на группе >= minGroupSize → удаление + спавн.
- special‑клик → эффект + спавн.

---

## 7) Перемешивание (ShuffleSystem)
**Что проверяем:**
- количество тайлов сохраняется;
- позиции изменяются, изменения отражены в `changes`.

**Тест‑кейсы:**
- Поле с N тайлами → после shuffle N тайлов, нет null‑потерь.

---

## 8) Бомба (BombSystem)
**Что проверяем:**
- удаление радиусом;
- корректная обработка границ;
- вызывает гравитацию.

**Тест‑кейсы:**
- radius=1 в центре → удаление 3x3.
- radius=2 у края → без выхода за границы.

---

## 9) Scoring (ScorePolicy + GameController)
**Что проверяем:**
- `ScorePolicy` применяется в `GameController`.

**Тест‑кейсы:**
- mock‑policy возвращает фиксированное число → `GameController` добавляет именно его.

---

# Набор утилит для тестов
- Локальный `TestBoardBuilder` для формирования сетки (чтобы писать тесты коротко).
- `FakeRng` для детерминированного выбора эффектов/спавна.
